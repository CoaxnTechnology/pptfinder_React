PPT Finder – Frontend

Internship Project

Developed By: Sahad Shaikh
Project Type: Full Stack Web Application (Frontend)
Technology: React.js

Project Description

This is the frontend part of the PPT Finder internship project.
It provides a clean and responsive user interface where users can search for PowerPoint (PPT/PPTX) files using keywords and view the results.

The frontend communicates with the FastAPI backend to fetch search results and display them to users.

Features

Keyword-based PPT search

Display PPT title, description, and link

Responsive and clean UI

React.js component-based structure

API integration with FastAPI backend

Technologies Used

React.js

JavaScript

HTML & CSS

How to Run (Frontend)
npm install
npm start
